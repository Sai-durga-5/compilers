# xv6 Shell & Memory | Course Lab

**Jan–Apr 2025**
**Guide:** Prof. Mythili Vutukuru | Operating Systems Lab

## Overview

Implemented and explored operating-system concepts in **xv6**, including shell development, system calls, inter-process communication, multithreading, synchronization, and shared memory.

## Key Learnings & Implementation

* Built a simple Unix shell using `fork()`, `exec()`, `wait()`, and `exit()` system calls.
* Practiced **inter-process communication (IPC)** and solved OS programming problems in xv6.
* Worked with the **pthreads API** and implemented multithreaded programs to improve execution speed.
* Used **locks and mutexes** for synchronization and safe concurrent access.
* Used the `mmap()` system call for **shared-memory communication between processes**.
* Successfully implemented and tested the programs on an **x86 emulator using QEMU**.

## Technologies

**C, xv6, Unix System Calls, pthreads, IPC, Locks, Mutexes, mmap, QEMU**
